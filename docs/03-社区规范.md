## 0. 这里是什么地方

一部**由她们自己落笔**的当代群芳志，也是一个允许关系慢慢发生的地方。

三条基本原则，贯穿全部规则：

1. **署名**：每一卷都有具体的人，不匿名、不代笔、不冒充；
2. **双向知情**：你读她，她知道你读过；她不想被读，可以关卷；
3. **内容先行**：先读自述，再看主图；先有具体的话，才有往来。

我们**不做**：相亲婚介、颜值排名、热门榜单、付费解锁聊天、直播带货、AI 生成人物。

## 第一条 零容忍红线

出现下列任一情形，内容立即下架、账号冻结、留存证据，必要时报警：

1. **涉及未成年人**：任何未成年人的形象、声音、个人信息，或由未成年人提交的内容；
2. **涉性内容**：淫秽、色情、低俗、擦边、性暗示，以及以身体为卖点的展示；
3. **人肉与骚扰**：披露他人真实身份、住址、单位、行程，跟踪、威胁、纠缠、辱骂；
4. **盗图与冒名**：搬运他人作品立卷，冒用他人身份、经历、手艺、资质；
5. **AI 换脸与拟声**：未经本人同意生成、替换、合成他人肖像或声音。

以上情形不适用「先警告后处理」，一律直接强制关闭账号。

## 第二条 立卷规范

2.1 **主体资格**：立卷人须年满 18 周岁并完成实名核验，一人一卷，不得代他人立卷。

2.2 **内容结构**：一卷应包含自述、题名、主图；缺项不予发布。

| 要素 | 要求 |
| --- | --- |
| 自述 | 150–300 字，第一人称、现在时；写「我在做」，不写「她曾……」；具体优于形容，可核对优先 |
| 题名 | ≤ 12 字，由立卷人自拟；编辑不得代改、不得提供「爆款标题」 |
| 主图 | **单张**，不得使用九宫格、照片墙、图集连拍 |
| 地域 | 默认只到大区；城市字段由本人决定是否开启 |

2.3 **原创与授权**：文字、照片、声音须为本人原创或已获合法授权；主图中出现他人可识别肖像的，须取得其书面同意并留存（模板见《用户投稿协议》附录 B）。

2.4 **图片处理**：上传即剥离 EXIF 等元数据；站方统一加印（本人印 + 站名），不提供原图下载。

2.5 **AI 使用**：允许用 AI 辅助排版、翻译、图片修复，须在页脚标注；**禁止**用 AI 生成人物、自述、声音，禁止生成「想象中的她」。

2.6 **不得包含**：商业广告、联系方式、二维码、外部账号导流、募捐与投资诱导、虚假经历。

## 第三条 题跋规范

题跋是写给具体一句话的回应，不是评论区。

3.1 **必须锚定**：引用原文中的具体一句，不得泛泛而谈。

3.2 **长度与内容**：不少于 **30 字**，包含「一个具体回应 + 你自己的身份或经验」。

3.3 **禁止**：

- 「写得好」「支持」「学到了」等无信息量回应；
- 对容貌、身材、年龄、婚况的评价；
- 盖楼式对话、表情包刷屏、@ 他人；
- 广告、人身攻击、贬损、引战、性别对立。

3.4 **她的选择权**：立卷人可「不收此跋」，被拒的题跋仅作者本人可见，不通知、不解释、不可申诉。

3.5 **数量限制**：同一用户对同一卷 7 日内仅可提交 1 条题跋，防止刷屏。

## 第四条 投书与互动

4.1 **她先开口**：投书默认关闭，由立卷人主动开启，可选择「需申请」；任何人不得绕过许可直接私信。

4.2 **慢递**：投书与回信均延迟 **24 小时**送达；不显示「正在输入」「已读」「在线」「最后活跃时间」。

4.3 **内容要求**：投书 ≤ 500 字，说明「我是谁、为什么写给你、我在做什么」；禁止模板化问候与外貌评价。

4.4 **禁止**：

- 索取手机号、微信、住址、单位、行程；
- 群发、复制粘贴同一内容给多人；
- 涉及金钱、投资、借贷、代购、兼职的话题；
- 以「交友」「相亲」「脱单」为名施压。

4.5 **拉黑**：被拉黑后，对方在全站范围内无法查看你的卷、无法投书、无法题跋；拉黑即时生效。

4.6 **不限流催促**：不得要求对方「秒回」；连续追问、变相施压按骚扰处理。

## 第五条 可见性与隐私

5.1 **读过的人名录**：每卷展示「读过的人」，仅立卷人可见，访客之间互不可见。这是**双向知情**，不是监视。

5.2 **首次提示**：访客首次进入人物卷时，页面明确提示「她将看到你读过」。

5.3 **关闭可见**：立卷人可对特定访客关闭可见，对方仍能读公开内容，但不再出现在名录中。

5.4 **不得外传**：不得截图、录屏、下载并搬运他人卷、题跋、投书至站外；发现外泄可举报。

5.5 **不得拼接**：不得将地名、口音、活动照片、工作场景等公开信息拼合，反推他人真实身份或位置。

5.6 **搜索收录**：卷默认允许搜索引擎收录；立卷人可单卷申请不索引。

## 第六条 禁止行为与处理

| 行为 | 处理 |
| --- | --- |
| 盗图、搬运、冒名立卷 | 下架 + 冻结 + 记录；情节严重者注销并公示 |
| 骚扰、纠缠、威胁、辱骂 | 首次警告并限制投书；再次冻结 |
| 诈骗、杀猪盘、诱导投资 | 立即冻结 + 留存证据 + 报警 |
| 广告、导流、二维码、联系方式 | 删除 + 警告；三次以上限制投稿 |
| 恶意题跋、外貌评价、引战 | 删除 + 警告；屡犯限制题跋 |
| 爬虫抓取、批量注册、规避实名 | 封禁 IP 与设备 + 注销账号 |
| AI 换脸、拟声、生成人物 | 立即下架 + 冻结 + 报警 |
| 传播站内截图至站外 | 警告 + 删除；造成损害者追偿 |
| 买卖账号、代实名 | 注销账号，不予恢复 |
| 组织违规线下聚会 | 取消资格 + 冻结 + 必要时报警 |

## 第七条 线下雅集

7.1 雅集须由立卷人发起，经站方审核，公开场地举办，单场不超过 **12 人**，可结伴参加。

7.2 禁止：一对一约见撮合、酒精主题聚会、私密场所、收费介绍、未成年人参加。

7.3 费用应事先公开、按实际支出分摊，不得以活动名义营利。

7.4 参加者须阅读安全须知并确认；涉及人身安全的风险由发起人与参加者自行评估，站方提供必要协助。

## 第八条 举报

8.1 举报入口全站可达，位于每卷、每条题跋、每封投书的操作菜单中。

8.2 举报时请尽量提供：内容链接、违规类型、截图或说明。我们承诺对举报人身份保密。

8.3 处置时限：

| 级别 | 类型 | 时限 |
| --- | --- | --- |
| P0 | 未成年人、涉性内容、人身安全威胁 | 1 小时内 |
| P1 | 盗图、冒名、骚扰、诈骗 | 24 小时内 |
| P2 | 不当言论、广告导流 | 72 小时内 |
| P3 | 内容争议 | 7 日内 |

8.4 恶意举报、反复虚假举报的，按第六条处理。

## 第九条 违规处理阶梯

9.1 一般违规按下列阶梯处理，可单独或合并适用：

1. 书面警告；
2. 删除或下架内容；
3. 限制题跋或投书权限（7 日／30 日）；
4. 冻结账号（内容不可见）；
5. 注销账号；
6. 追偿损失；
7. 向监管部门报告或移送司法机关。

9.2 **从重情节**：涉及未成年人、涉性内容、诈骗、累犯、组织化违规、造成实际损害。

9.3 **从轻情节**：首次违规、主动删除、如实说明、积极配合处置。

9.4 因违规被下架的内容，站方留存处置记录不少于 6 个月。

## 第十条 申诉

10.1 你对处置结果有异议的，可在收到通知后 **7 日**内通过站内申诉入口提交一次申诉。

10.2 申诉应包含：账号信息、被处置内容、申诉理由与证明材料。

10.3 我们将在 **7 个工作日**内复核并答复。复核期间，原处置措施不停止执行。

10.4 涉及未成年人与涉性内容的处置，不接受申诉恢复。

## 第十一条 规范更新

11.1 本规范修订时更新版本号，并在站内公告 **7 日**。

11.2 涉及零容忍红线、处理阶梯、申诉规则的重大变更，将在公告中显著标识；你继续使用服务视为接受。

11.3 你不同意修订内容的，可停止使用并注销账号。

## 第十二条 与其他文件的关系

12.1 本规范与《用户投稿协议》《隐私政策》共同构成完整约定：

- 投稿的权利归属与授权范围，以《用户投稿协议》为准；
- 个人信息处理规则，以《隐私政策》为准；
- 内容与行为边界、处置与申诉，以本规范为准。

12.2 本规范未尽事项，按法律法规与站方公示的其他规则处理。

## 附 · 快速判断

| 情境 | 可以 | 不可以 |
| --- | --- | --- |
| 读到一卷很有共鸣 | 写一条锚定原句、≥30 字的题跋 | 只写「好看」「支持」，或评价她的外貌 |
